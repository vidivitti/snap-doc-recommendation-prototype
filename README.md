# DTA Discovery | Verification List Prototype

React/Vite prototype for SNAP verification recommendations.

## Local preview

Install dependencies, then run the local dev server:

```bash
pnpm install
pnpm run dev
```

Open the local URL shown in the terminal.

## Prototype password

The prototype includes a lightweight password gate for casual review access.

Password: `DTAproof2026`

This is not strong security. For sensitive content, use platform-level access control.

## Vercel settings

Use these settings when importing this repo into Vercel:

- Framework preset: `Vite`
- Build command: `pnpm run build`
- Output directory: `dist`
- App/root directory: `/`
